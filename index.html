GitHub Pages Generator & Deployer

Export your customized chat app with your current theme & channels baked in

Production `index.html` (Self-Contained)

Single-file web application pre-configured with your active Midnight Nebula theme and custom channels. Zero build step required for GitHub Pages.

Repository `README.md`

Automatically generated documentation featuring your live GitHub Pages badge, custom theme specification table, and setup guide.

How to host on GitHub Pages in 30 seconds: 1. Click Download index.html above.
2. Create a new public repository on github.com/new and upload `index.html`.
3. Go to repository Settings → Pages, select the `main` branch, and click Save!

Provide a GitHub Personal Access Token (with `repo` or `public_repo` scope) to automatically create the repository and commit your customized `index.html` and `README.md` directly from your browser.

Your token is only sent directly to `api.github.com` and is never stored.

After downloading `index.html` and `README.md` into a folder on your computer, run these terminal commands to publish:

mkdir nexus-chat-custom && cd nexus-chat-custom
# Move your downloaded index.html and README.md into this directory
git init
git add index.html README.md
git commit -m "Initial commit: Custom NexusChat web application"
git branch -M main
git remote add origin https://github.com/your-username/nexus-chat-custom.git
git push -u origin main
Open GitHub New Repository
